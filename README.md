# AI Chat Assistant

I built a fully configurable AI Chat Assistant that lets users have natural, streaming conversations with a customizable large language model. The application is built with Streamlit and the Groq API, giving users full control over system instructions, expertise domains, and conversation context while keeping the experience fast and intuitive.

Users can define custom system prompts, select different areas of expertise, maintain persistent chat history, and securely manage their API keys — all through a clean sidebar interface. The assistant streams responses in real time and supports dynamic context injection for more useful, personalized interactions.

## Features

- Live token streaming responses
- User-defined system instructions
- Selectable expertise domains
- Persistent chat history
- Secure API key handling
- Clean, customizable sidebar UI

## Tech Stack

- Python
- Streamlit
- Groq API
- Dynamic Prompting & Context Injection
